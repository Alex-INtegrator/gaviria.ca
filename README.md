# gaviria.ca

Personal website of Alejandro /Alex/ Gaviria — FR (`/`), EN (`/en/`), ES (`/es/`).

- `content.py` — all the text, in French, English and Spanish. Edit here.
- `site.css` — styles (colours and type from the design system).
- `img/` — photos. `favicon.svg` — AG monogram.
- `build.py` — regenerates the website into `docs/`.
- `docs/` — the published website (do not edit by hand; it is rebuilt).

Update: edit `content.py`, run `python3 build.py`, then commit and push.
